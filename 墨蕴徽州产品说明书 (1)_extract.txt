墨蕴徽州
——徽文化数字文创智造平台
产品说明书
总体介绍
1. 项目背景与问题提出
徽州文化是中华传统文化的重要组成部分，涵盖了徽派建筑、文房四宝、徽商文化、徽剧与黄梅戏、徽州三雕、新安画派、民俗饮食等众多门类，资源底蕴深厚。其中，宏村、西递等皖南古村落被列入世界文化遗产，徽墨、歙砚、徽州三雕等多项技艺列入国家级非物质文化遗产名录。然而，徽文化资源的传播与转化长期面临以下问题：
一是传播形式较为单一。多数文化资源仍以实体场馆展示、图文展览和旅游观光为主，数字化呈现多为静态的图文页面，缺少能够让用户参与其中的互动形式，年轻人很难对这类内容保持长久的兴趣。
二是文创产品同质化严重。旅游文创市场中的产品大量采用通用模板，缺乏地域文化内核；而带有徽文化元素的个性化设计，从创意到设计稿通常需要专业设计师投入数天时间，定制成本高、周期长，普通用户几乎无法参与。
三是通用人工智能工具对徽文化&quot;水土不服&quot;。近年文生图模型能够根据自然语言描述生成图像，但通用模型缺乏对马头墙、四水归堂、徽墨、三雕等徽文化元素的专门理解，生成结果常出现建筑形态失真、风格混杂等问题；通用对话模型对徽文化知识的回答也缺乏可靠依据，存在编造信息的风险。
上述问题表明，亟需一套面向徽文化的、将文化理解、内容生成与文创转化结合起来的智能化工具，让用户能够低成本地&quot;画出徽州、讲出徽州、造出徽州文创&quot;。
2. 解决方案概述
本项目研发了一套基于生成式人工智能（AIGC）的徽文化数字文创智造平台，围绕&quot;画徽州、讲徽州、造文创&quot;三个环节提供服务：一是通过徽派风格 LoRA 模型或云生图API，用户输入一句自然语言描述即可生成具有徽派建筑与水墨山水风格的数字画作；二是通过构建徽文化知识库并采用检索增强生成（RAG）技术，为用户提供有据可查的徽文化问答；三是将生成的画作一键套用明信片、海报、书签等模板，导出可直接打印的高清文创成品。
平台由四个功能模块组成：徽州意象馆（文旅数字大屏）、AI 徽画工坊（徽派风格图像生成）、徽史问答官（徽文化知识问答）、文创印务局（文创成品合成与导出）。四个模块共用一个后端调度中心与图像生成引擎，把文化展示、内容生成和实物转化串成一条完整的流程。
3. 系统架构图
平台采用前后端分离的架构。前端为基于 Vue3 的单页应用，包含四个功能页面与一个文旅数字大屏，负责用户交互与结果展示；后端为基于 FastAPI 的调度中心，向下接驳三个核心服务：图像生成引擎、RAG 知识问答服务和文创合成服务。
图像生成引擎采用可插拔设计，支持两种运行模式：本地模式在本机 GPU 上运行 SDXL 基础模型并叠加自训的徽派 LoRA 权重，可离线出图；云 API 模式调用云生图平台接口作为备用。两种模式对外暴露统一的生成接口，切换无需修改业务代码。其中，界面面向用户提供&quot;本地徽派 LoRA&quot;与&quot;云端智库&quot;两种可选出图引擎，分别对应本地推理与云 API 两种模式。RAG 问答服务在本地完成知识切块、向量化与检索，再调用大模型生成回答。文创合成服务使用图像处理库将生成画作与排版模板合成最终成品。系统架构如图1-1所示。

4. 产品预期效果
本产品投入应用后，预期在以下几个方面产生明显效果。
在降低创作门槛方面，用户无需具备美术设计基础，仅需用一句话描述画面，即可在数秒至数十秒内得到一幅徽派风格的画作，并可进一步制成明信片、海报等文创成品，让没有美术基础的普通用户也能做出徽州文创。
在提升文化准确性方面，通过针对徽文化元素专门微调的 LoRA 模型，生成画面的建筑形态与水墨风格更贴合徽文化特征；问答模块的回答均依据本地知识库检索结果生成并标注出处，降低了大模型编造信息的风险。
在提高制作效率方面，从文字描述到文创成品导出的全流程可在分钟级内完成，相比传统人工设计（通常需要数天）效率明显提升，适合景区现场、展会等需要快速出结果的场合。
在环境适应性方面，图像生成与知识检索均可在本地运行，即使现场网络不稳定，系统仍能完成主要的生成与问答演示，适合校赛、展会等演示环境。
5. 应用场景与总结
在文旅景区与博物馆场景中，本产品可作为游客互动体验工具：游客现场输入描述即可生成徽派画作并制成明信片带走，也可通过问答模块了解景点背后的文化故事，让游客既能动手创作，又能了解文化。
在学校教育与美育场景中，本产品可作为传统文化课程的实践工具，学生通过实际生成画作、提问探究，直观理解徽文化的审美特征与历史脉络，培养对传统文化的兴趣。
在文创电商与企业定制场景中，本产品可快速产出创意样稿，支撑明信片、书签、海报等衍生品的打样与批量定制，缩短文创产品的开发周期。
综上所述，本产品把文化展示、内容生成和文创转化放在同一个平台上，让文化资源变成用户可以参与、可以生成、可以带走的东西，为徽文化的保护、传播和利用提供了新的办法。

1. 徽州意象馆——文旅数字大屏
徽州意象馆是平台的展示层，面向文旅宣传与展览场景，在一屏之内总览徽州文化圈的整体面貌。大屏以安徽省地图为底，标注了黄山市、宣城市、池州市、安庆市、芜湖市、马鞍山市、六安市、滁州市八个城市的 43 处徽文化景点，景点清单与景区等级均经公开资料核实。景点按性质分为山水自然、徽州古村落、人文古迹与非遗、主题乐园与城市四类，在地图上以不同颜色区分。
大屏同时展示国家级与省级非遗名录（含徽州三雕、徽墨制作技艺、歙砚制作技艺、徽州传统民居营造技艺、万安罗盘制作技艺等）、文化圈城市分布、游客画像、热词与资讯滚动条等看板内容，形成&quot;景点—非遗—城市—数据&quot;的多层次展示结构。
在技术实现上，大屏采用 ECharts 的 registerMap 接口注册安徽省级地理数据，以散点与涟漪动画标注景点位置；整体按 1920×1080 设计，通过自适应缩放方案适配不同分辨率的显示屏。界面沿用徽州风格的配色与样式：宣纸米白底色、水墨晕染背景、朱砂与鎏金点缀，与平台整体视觉风格保持一致。需要说明的是，大屏中的游客量等统计指标目前为演示口径，正式应用中接入实时数据源。

2. AI 徽画工坊——徽派风格图像生成
AI 徽画工坊是平台的核心生成模块。用户输入一句画面描述，选择风格与画幅，即可生成一幅徽派风格的数字画作。模块支持水墨、写实两种风格，1:1、3:4、4:5、9:16、16:9 五种画幅，单张与四宫格两种生成方式，并提供&quot;徽派建筑、山水烟雨、器物文房、民俗人物&quot;四类灵感提示词引导用户描述画面，生成结果自动存入历史记录，可回看与放大。此外，模块提供&quot;出图引擎&quot;选择，用户可在&quot;本地徽派 LoRA&quot;与&quot;云端智库&quot;两种引擎之间自主选择生图方式，兼顾自研模型与云端模型的各自优势。
模块的技术方案包含以下几个部分。
（1）扩散模型与文生图原理。文生图模型属于扩散模型一类，其生成过程可理解为从纯噪声图像出发，在文本描述的引导下逐步去噪，最终还原为与描述相符的图像。模型在训练阶段学习了海量图文对中&quot;文本—图像&quot;的对应关系，因此能够理解自然语言描述并生成对应画面。然而，通用模型对徽文化这类专业领域的知识有限，直接生成的结果在建筑形制、风格韵味上往往不够准确，需要针对性地微调。
（2）LoRA 低秩微调。对大型生成模型进行全量微调需要高昂的算力与存储开销，LoRA（低秩适配）方法提供了一种轻量方案：冻结预训练模型的原始权重，只训练一个低秩的增量矩阵。设预训练权重为 W₀，LoRA 将增量 ΔW 分解为两个低秩矩阵 B 与 A 的乘积，微调后的权重为：

（3）自训徽派 LoRA。团队收集了公开授权图库中的徽派建筑、水墨山水等素材，经筛选、清洗与标注后，分别训练了两枚徽派 LoRA 权重：一枚以写实徽州古村落为主（突出马头墙、白墙黛瓦等建筑特征），一枚以水墨风格为主（突出墨韵、留白等绘画特征）。两枚权重可以同时加载并叠加使用。
（4）双 LoRA 叠加与风格控制。模块通过设置两枚 LoRA 的叠加强度（adapter_weights）实现风格连续调节：水墨风格提高水墨权重的叠加强度，写实风格提高建筑权重的叠加强度，平衡风格则两者并重。三种风格的配比参数如表2-2所示。此外，生成过程设置了默认负向提示词，抑制人像、现代室内等与徽派主题不符的元素，提高出图成功率。

（6）生成稳定性设计。固定随机种子可复现同一描述对应的同一画面，便于前后对比与模板复用；四宫格生成采用排队方式逐格出图，避免显存瞬时压力过大；风格参数预设经过验证，保证现场演示的出图效果稳定。AI 徽画工坊界面如图2-2所示。

3. 徽史问答官——基于检索增强生成的徽文化问答
徽史问答官是平台的知识问答模块。用户就徽文化提出问题，系统返回有据可查的回答，并在回答中标注所引用的资料来源。模块支持多会话管理，最多保留20个历史会话；根据用户问题的关键词自动推荐延伸追问，帮助用户深入了解相关内容。
模块的技术方案包含以下几个部分。
（1）知识库构建。团队整理并录入了徽派建筑、文房四宝、徽商文化、徽剧与黄梅戏、徽州三雕、民俗饮食、新安医学、新安画派等门类的徽文化专题资料六十余篇，来源均为公开可查的权威资料。原始文本按固定长度切块并保留重叠区间，避免上下文断裂，共构建约 900 条检索单元。
（2）文本向量化与语义检索。计算机无法直接比较两段文字的语义，需要先将文本映射为向量（一组数值），使语义相近的文本对应的向量在空间中相互靠近。检索时，将用户问题同样映射为向量，再在知识库中找出与其最相近的若干条资料。这里使用余弦相似度衡量两个向量 q 与 d 的相近程度：

（3）本地向量化与向量库。大模型厂商的对话接口一般不提供文本向量化接口，因此平台采用本地部署的中文专用向量模型 bge-base-zh-v1.5 完成向量化，该模型体积适中、可用 CPU 运行，无需 GPU；向量库采用 ChromaDB，使用余弦距离组织向量并持久化存储，检索结果可复现。
（4）大模型生成回答。问答流程为先检索后生成：系统检索出与问题最相关的若干条资料（默认 5 条），将其与问题一起组装为提示词，交给大模型（DeepSeek）生成回答。提示词中明确要求模型仅依据提供的资料作答，资料不足时如实说明，并在回答末尾标注用到了哪几条资料，从而保证回答内容可追溯、可核对。徽史问答官界面如图2-3所示。

4. 文创印务局——文创成品合成与导出
文创印务局负责把生成好的画作做成文创成品。用户选定一张已生成的画作，输入标题与副题，即可合成明信片、海报或书签等文创成品，并可下载高清 PNG 图片用于打印。模块支持&quot;同一幅画换模板&quot;：由于生成画作由随机种子唯一确定，用户切换模板或修改版式时，系统复用同一画面重新排版，无需重新生成，方便快速比较不同版式的效果。
在技术实现上，文创合成采用&quot;生成画作 + 图像处理排版&quot;的方案：先将画作按比例缩放至模板的图画区域，再叠加标题、副题、装饰元素与落款，最终输出成品图像。排版沿用统一的徽州配色与样式——宣纸米白底色、砚墨字色、朱砂印章、鎏金描边，标题采用楷体类字体并降级处理，保证在不同系统环境下均能正常渲染。三种模板的规格与版式特点如表2-3所示。

（三）产品创新点
本产品在技术实现、产品形态与工程实践三个层面形成了以下创新点。
第一，自研徽派风格 LoRA 与双模型叠加控制。团队针对徽文化元素专门训练了两枚 LoRA 权重，使生成画面在建筑形制（马头墙、白墙黛瓦、四水归堂）与水墨韵味上明显优于通用文生图模型；同时通过叠加强度配比实现&quot;水墨—写实&quot;风格的连续调节，同一描述即可得到风格不同的多幅作品，这一&quot;可调风格的双 LoRA 叠加&quot;方案是通用绘画工具不具备的能力。
第二，&quot;生图—问答—文创&quot;一体化的产品形态。平台把图像生成、知识问答和文创转化放在一起：同一套底层能力，既支持游客现场生成画作，也支持文化讲解问答，还支持把作品直接做成可带走的文创成品。相比只做单一生图或单一问答的工具，平台的功能更完整，覆盖了人们从体验文化到带走成品的全过程。
第三，检索增强的可追溯问答。针对大模型回答不可控、易编造的问题，平台采用&quot;本地知识库检索 + 大模型生成&quot;的 RAG 方案：回答必须依据检索到的资料生成并标注来源，资料不足时如实说明。这一机制使知识问答可信、可核对，适合文化传播类场景对内容准确性的要求。
第四，可插拔生图架构与离线演示能力。生图引擎对上层暴露统一接口，底层支持本地、云 API 两种模式，并在界面内向用户开放&quot;本地徽派 LoRA / 云端智库&quot;两种出图引擎的自由选择。本地模式在无网络的条件下仍能完成生成演示，极大增强了产品在展会、课堂等现场环境的可用性，也降低了部署成本。
第五，统一的徽州视觉风格。平台把宣纸、水墨、朱砂、鎏金这些徽州文化符号整理成一套统一的配色与样式，用在文旅大屏、生成画作和文创成品上，让整个产品的风格一致，一眼就能看出徽州特色。
（四）市场分析
当前，文化数字化的工具越来越普及，游客也更愿意接受个性化、可参与的数字产品。本产品针对徽文化传播和文创生产中的具体问题来做，目标用户比较明确。
1. 痛点分析
一是文创产品同质化。旅游文创市场产品趋同，大量使用通用模板与图案，缺乏地域文化辨识度，难以满足游客对&quot;有文化、有特色&quot;纪念品的需求。
二是设计门槛与成本高。将文化元素转化为可用设计稿需要专业设计能力，个性化定制通常价格高、周期长，中小景区与个体商户难以承担，限制了文创产品的多样性。
三是文化传播单向、游客参与不足。文博与旅游场景的数字化内容多为静态图文，游客缺乏可参与的互动环节，文化内容很难被游客记住，也不容易被分享出去。
四是通用 AI 工具难以直接落地。通用文生图模型不懂徽文化元素，生成结果需要大量人工修正；通用问答模型缺乏本地知识依据，回答准确性无法保证。市场上的现成工具均未针对徽文化场景做专门适配。

3. 应用示范设想
在文旅景区与博物馆，可部署&quot;AI 徽州文创体验点&quot;：游客现场生成画作并制成明信片、书签等纪念品，问答模块同步提供文化讲解，让游客既做了纪念品、又了解了文化，也更愿意把见闻分享给别人。
在校园与研学场景，可作为传统文化课程的教学工具：学生通过实际操作理解 AI 生成原理与徽文化内涵，平台同时为非遗技艺、建筑形制等教学内容提供可视化素材与互动问答。
在文创电商与企业定制场景，可用于快速打样与批量生产：运营方输入主题描述即可批量生成系列化样稿，经筛选后进入定制生产，明显缩短文创产品从创意到做出成品的周期。
4. 商业模式与推广渠道
本产品拟采用&quot;基础服务 + 增值服务&quot;相结合的商业模式：基础层面提供在线生成与问答功能，面向个人用户免费或低价开放，培养使用习惯；增值层面提供高清无水印导出、批量生成、模板定制与私有化部署等服务，面向景区、学校与企业收费。
推广渠道方面，重点与文旅景区、博物馆等文化机构合作，先以体验点形式落地做出示范；与高校传统文化课程、创新创业教育机构合作进入教学场景；与文创电商平台合作提供生成能力与定制服务，让更多人认识和使用这款产品。
