# 《墨蕴徽州》项目技术方案书

> 项目定位：**基于 AIGC 的徽文化数字文创智造平台**
> 参赛赛道：iCAN 创新赛道 · **智慧文创**方向（官方 10 方向之一）
> 团队：王昱晗、陈树健（纯软件团队，2 人）
> 文档版本：v1.0（对齐契约）

---

## 一、项目一句话定位

以徽派建筑、宣纸水墨、徽州三雕等徽文化为素材基底，用 AIGC 让每个人都能一键"**画出徽州、讲出徽州、造出徽州文创**"的智能平台。

## 二、赛道契合点

- 官方创新赛道 10 方向之一：**智慧文创**（"用于提升文化娱乐生活的文创产品和服务"）。
- 2026 官方风向词：人工智能、智能制造、集成电路、智能机器人、航空航天、生物医药、低空经济、新型储能 → 本项目的 **人工智能 + AIGC** 完全踩中。
- 地域特色：合肥工业大学宣城校区地处安徽，徽文化是天然加分项。

## 三、产品功能模块（4 个，砍掉语音）

| # | 模块 | 功能 | 本质 |
|---|------|------|------|
| ① | 徽州意象馆 | 文旅宣传展示（大屏/画廊） | 展示层 |
| ② | AI 徽画工坊 | AI 生图（核心引擎） | **生图引擎** |
| ③ | 徽史问答官 | 智能体知识库问答（RAG） | 文本智能 |
| ④ | 文创印务局 | 生成文创成品（海报/明信片/书签） | **生图引擎 + 模板合成** |

> ② 与 ④ 共用同一个生图引擎，④ 是"生图 + 模板排版 + 商业闭环"。

## 四、技术架构

```
浏览器（Vue3 前端）
   │ HTTP请求
   ▼
FastAPI 后端（调度中心）
   ├─▶ 图像生成服务（可插拔）
   │     ├─ local_sd：本地/远程 GPU 跑 SDXL + 徽派LoRA（自研亮点）
   │     └─ remote_api：云生图 API（明确标注的备胎）
   ├─▶ RAG 问答
   │     本地向量库(ChromaDB/FAISS) + bge-m3 embedding(CPU) + DeepSeek API
   └─▶ 文创合成
        Pillow 模板渲染 → 导出高清图
```

### 技术选型（已对齐）

| 层 | 选型 | 理由 |
|----|------|------|
| 前端 | **Vue3 + Vite + Element Plus + ECharts** | 团队会 Vue；文旅大屏有现成开源模板可改 |
| 后端 | **FastAPI** | 与去年 pyService 同栈有代码参考；异步+自动文档 |
| 生图 | **本地 SDXL + 自训徽派 LoRA（主）+ 云 API（明示备胎）** | 自研技术亮点、可离线演示、创新性分 |
| 生图数据 | **精选公开 CC 图库 100~300 张 + 严格清洗打标** | 假期无法实地采风；CC 授权合法 |
| RAG | **bge-m3 embedding（本地CPU）+ ChromaDB + DeepSeek API** | DeepSeek 无 embedding 接口；本地向量化免费 |
| 文创 | **Pillow 模板合成** | 简单可靠 |

### 算力分配

| 任务 | 跑在哪 | 说明 |
|------|--------|------|
| LoRA 训练 | **远程 5080**（或 Colab 兜底） | 单卡 16GB，LoRA 训练 8~12GB 足够 |
| 生图推理 | 远程 5080 / 演示机 GPU / 云 API | 通过可插拔服务切换 |
| RAG 向量化 | 本地 CPU（bge-m3） | 轻量，不占 GPU |
| 大模型问答 | DeepSeek API | 云端 |

## 五、诚信与合规（关键底线）

1. **演示所见即本地模型所产**：图像生成演示链路走本地 LoRA，断网也能出图；任何使用云 API 的地方在材料中白纸黑字标注。
2. **2026 新规**：AI 辅助制作材料须标注"AI辅助制作"；原创材料（开发日志）齐全；数据来源清单完整。
3. **版权**：训练图只用 CC/CC0 授权图库；知识库文本用公开可商用来源；全部记录来源。
4. **材料与实物一致**：产品说明书/PPT 描述的功能 = 实际系统功能，杜绝去年"说 Streamlit 实际 Next.js"的硬伤。

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| LoRA 效果不稳定 | 预设 3~5 组风格模板参数，现场演示稳定出图 |
| 演示机器无 GPU | 生图服务可插拔：远程 GPU / Colab / 云 API 切换；备好录屏 |
| 数据集质量差 | 严格清洗打标；宁缺毋滥（100~300 张高质量） |
| 现场断网 | 生图本地跑；RAG 预置兜底回答 |
| 3 周太紧 | 保"生图+问答+文创"三核心，砍非核心功能 |
