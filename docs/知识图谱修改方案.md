# 徽史问答官知识图谱修改方案

日期：2026-10-13。以当前本地源码及知识库为准，参考《墨蕴徽州_项目结构与关键代码》与现有交付说明。

## 一、项目梳理

| 层次 | 关键文件 | 当前职责 |
| --- | --- | --- |
| 前端壳与路由 | `frontend/src/App.vue`、`router/index.js`、`style.css` | Vue 3 单页应用；Element Plus；宣纸、墨色、朱砂和楷体设计；大屏独立全屏 |
| 展示层 | `views/Home.vue`、`bigscreen/` | 首页与 ECharts 文旅大屏；ECharts 已安装，可直接复用 |
| 徽史问答官 | `views/Ask.vue`、`api/index.js` | 多会话本地存储、打字效果、来源阅读、追问；调用 POST `/api/ask` |
| 后端调度 | `backend/app/main.py`、`routes/`、`config.py` | FastAPI 路由与配置；已有 ask 路由可承载新接口 |
| 知识读取 | `rag/knowledge.py`、`app/data/*.txt` | 当前 60 篇资料；兼容 JSONL；按 200 字、50 字重叠切块 |
| 检索问答 | `rag/vectorstore.py`、`rag/retriever.py` | 实际使用本地 `bge-base-zh-v1.5`，ChromaDB 持久化，前五段检索结果交给 DeepSeek；部分旧注释仍写 bge-m3 |
| 图像推理 | `image_gen/`、`routes/generate.py` | SDXL FP16 + 建筑/水墨 LoRA，CUDA 懒加载；模式切换和缓存；云端图像接口 |
| 文创合成 | `routes/export.py`、`export/composer.py`、`views/Craft.vue` | 复用生图引擎，经 Pillow 输出明信片、海报、书签 |

知识库资料覆盖建筑、徽商、文房、戏曲、民俗、工艺、书画学术、医学、历史人物。文本中没有统一来源网址或现成实体关系三元组，因此以真实文件与原文作为可追溯依据，不补造来源、人物关系或历史断言。

## 二、具体设计

1. 将知识库读取拆出带标题与来源标识的条目函数；原 `load_knowledge_texts()` 仍返回相同文本，切块、向量索引和问答流程保持原行为。
2. 新增 `rag/graph.py`，按标题关键词整理 9 个阅读主题。图中包含根节点、主题节点、资料节点；主题归属是展示分类。跨资料连线仅表示至少两个文化关键词在两篇原文中共同出现，每篇最多两条此类连线，控制密度。节点 ID 由来源标识稳定生成。
3. 在已有 ask 路由内增加 GET `/api/ask/knowledge-graph`，每次读取同一知识库返回节点、连线、主题和真实统计。不启动向量模型，不调用 DeepSeek，不引入数据库、依赖或持久缓存。
4. `/ask` 改为路由分组，原问答作为默认子页面，新建 `/ask/knowledge`。导航仍高亮“徽史问答官”；问答页添加图谱入口，图谱提供返回链接。
5. 新建 `KnowledgeGraph.vue`，复用 ECharts 与全局设计变量。提供主题分布网络、节点与关系高亮、拖拽缩放、主题筛选、全文搜索、资料列表、原文详情、主题自动漫游、复位；支持窄屏布局与减少动画偏好。每个资料节点可带问题返回问答输入框，由用户发送。
6. 保留必要的加载、空数据、无搜索结果与接口失败提示。实现直接的数据流，不添加通用防御层、冗余兼容代码、异常吞噬或伪造示例知识。

## 三、修改范围

修改 6 个现有文件：`rag/knowledge.py`、`routes/ask.py`、`frontend/src/api/index.js`、`router/index.js`、`App.vue`、`views/Ask.vue`。

新增 2 个运行文件：`rag/graph.py`、`views/KnowledgeGraph.vue`。另附必要的后端数据测试、本方案与交付说明。保持现有依赖清单、环境文件、模型权重、知识原文、向量数据库、生图实现不变。

仓库原有未提交修改予以保留；本次修改前已备份上述现有文件，用于生成仅包含本次变动的补丁。同步包中的完整替换文件基于当前本地版本，其中 `Ask.vue` 和 `api/index.js` 包含原本已有的修改，交付说明将特别提示。

## 四、验收与交付

- 验证原知识文本与切块结果不变；60 篇文本完整覆盖；ID 稳定、连线无悬空，统计真实；JSONL、空库、关键词关系依据成立。
- 验证新 GET 接口与原 POST 接口共存，图谱请求不加载 PyTorch、Embedding 或 ChromaDB；执行前端生产构建。
- 浏览器检查桌面与窄屏、主题筛选、搜索、节点详情、原文展开、漫游暂停、复位、带问题返回与异常状态。
