## 一、项目概述

徽文化数字文创智造平台，前端 Vite + Vue3，后端 FastAPI。核心功能：
- **徽史问答官**（RAG + DeepSeek 大模型问答）
- **AI 徽画工坊**（文生图，本地 / 云端双引擎，可一键切换）
- **文创印物馆**（生图结果套模板导出明信片/海报/书签）
- **城市智慧大屏**（数据可视化）

生图能力基于自训的两枚徽州 LoRA（建筑 + 水墨）与智谱云文生图 API。

---

## 二、生图双模式（本项目最终形态）

| 模式 | 引擎 | 特点 | 依赖 |
|---|---|---|---|
| **local** | SDXL 1.0 + 徽州 LoRA（建筑 0.3 / 水墨 0.5，可叠加） | 徽州风格纯正 | CUDA GPU + diffusers + SDXL 模型 |
| **api** | 智谱 GLM-Image 云 API | 无 GPU 兜底，通用国风（无徽州 LoRA，带 AI 水印） | 智谱 API Key + 联网 |

> 远程模式（remote）经评估已**取消**，不在交付范围内。

模式由 `backend/.env` 的 `IMAGE_GEN_MODE` 决定，也可在**前端徽画工坊「出图引擎」按钮**一键切换（local/云 两个按钮，切换即时生效并持久化）。

## 四、启动方式

### 1. 环境准备（服务器，AutoDL 4090 示例）

```bash
# Python 3.10+，建议 conda 环境
conda activate lora   # 服务器上为训练用环境（已含 CUDA torch + diffusers）
pip install -r backend/requirements.txt
pip install -U diffusers transformers accelerate peft safetensors   # 生图依赖
apt-get install -y fonts-wqy-microhei   # 中文字体（文创标题渲染必需）
```

### 2. 后端

```bash
cd backend
# 关键：SDXL 本地模型路径 /root/autodl-tmp/sdxl-base 需存在（见注意事项）
uvicorn app.main:app --host 0.0.0.0 --port 8000
# 调试建议加 --reload
```

### 3. 前端

```bash
cd frontend
npm install
npm run dev            # Vite，默认 http://localhost:5173
```

### 4. 访问（服务器场景，SSH 隧道映射）

```powershell
ssh -CN -p <端口> -L 5173:localhost:5173 -L 8000:localhost:8000 root@<服务器>
# 浏览器打开 http://localhost:5173
```

## 五、使用说明

- **出图引擎切换**：徽画工坊 → 出图引擎按钮（本地徽州 LoRA / 云端智谱）。切换写入 `.env` 持久化，重启后保留。
- **风格**：前端可选 水墨/写实（对应 LoRA 叠加配比 `ink` / `photo` / `balanced`），叠加默认配比 1.2/1.2。
- **提示词**：本地模式建议用标准提示词（`徽州古村落, 马头墙, 白墙黛瓦, 屋顶, 建筑摄影, 无人物`；水墨用 `Chinese ink wash painting, brush strokes, 水墨山水…`）；云模式用通用国风描述。
- **负向提示词**：后端内置默认（压制人像/现代/室内），前端可覆盖。

## 六、注意事项（务必阅读）

1. **服务器专属路径**：`local_sd.py` 的 `model_id` 指向 `/root/autodl-tmp/sdxl-base`（训练阶段下载的 SDXL fp16 变体）。**部署到新机器必须确认该路径存在**；若改路径，请同步改 `local_sd.py` 或在代码中配置化。
2. **LoRA 权重**：`backend/models/lora/` 下两枚 `.safetensors`（各约 355MB，fp32）为自训交付物，不在 git 中（`.gitignore` 忽略），**打包交付必须单独带上**。
3. **`.env` 含密钥**：DeepSeek / 智谱 Key，不入库；部署方需自行填写。
4. **中文字体**：文创合成依赖系统字体。Linux 需 `fonts-wqy-microhei`；Windows 用系统微软雅黑/宋体（`composer.py` 候选已兼容双平台）。
5. **云模式限制**：智谱 API 无徽州 LoRA，出图是通用国风；默认带 AI 水印（去水印需在智谱平台签免责声明）；负向/seed/style 参数在云模式被忽略（符合预期）。
6. **前端启动目录**：`npm run dev` 必须在 `frontend/` 目录执行（package.json 在 `frontend/`）。
7. **`get_engine` 缓存与单进程**：模式切换的内存即时生效仅在**单进程 uvicorn** 下可靠；若用 `--workers > 1`，切换需依赖 `.env` + 重启。
8. **`.gitignore` 已忽略**：`.env`、`models/lora/*.safetensors`、`app/data/models/bge-base-zh-v1.5/`、`app/data/vector_store/`、`frontend/node_modules/`、`frontend/dist/` —— 这些**不在 git 里，交付时需单独打包**。
